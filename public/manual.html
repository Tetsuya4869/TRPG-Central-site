🐙 TRPG Central 説明書

クトゥルフ神話TRPG(6版/7版)の管理サイト TRPG Central の使い方ガイドです。 人間だけで遊ぶ卓の管理から、Claude がキーパー(GM)を務める AI GM プレイまで、このサイトひとつで完結します。

CoC 6版 / 7版 AI GM(Claude) 戦闘トラッカー キャンペーン継続 PWA対応

はじめての流れ

まず探索者を1人作り、遊び方に応じて「人間卓」か「AI GM」に進みます。

→

4終了後
成長チェック・あらすじ・続編

基本機能

📜 探索者管理

メニュー「探索者」。CoC 6版/7版の探索者シートを作成・管理します。

新規作成

1版(6版/7版)を選ぶ
→
2能力値を入力 or ダイスで自動ロール
→
3技能ポイントを割り振り
→
4保存
  • HP・MP・SAN・DB(ダメージボーナス)などの派生値は自動計算されます
  • 職業技能・趣味技能のポイント上限も版のルールに沿って自動管理
  • リストにない技能はカスタム技能として追加できます

Charaenoからインポート

7版のキャラクターシート作成サイト Charaeno のJSONを取り込めます。 探索者一覧の「⬇ インポート」からJSONファイルを選ぶだけです。

武器と立ち絵はインポート対象外です。取り込み後にシートで追加してください。

基本機能

🎲 ダイスローラー

メニュー「ダイス」。汎用ロールから7版の拡張ルールまで、すべてのダイスをここで振れます。

基本のロール

  • プリセット: 1d100 / 1d10 / 1d6 / 2d6 / 3d6 / 1d4 をワンタップ
  • 複合式: 1d6+1d4+2 のような式も入力できます
  • 技能判定: 目標値を入れて判定。6版はクリティカル/ファンブル、7版は成功度(イクストリーム/ハード)を自動判別

探索者を選んでワンタップ判定

探索者を選択すると、その探索者の技能が実効値付きのボタンで並びます。 SANチェック・アイデア・幸運・知識などの特殊判定もワンタップです。

7版の拡張ルール 7版

🍀 幸運消費

判定に失敗したとき、「幸運で成功にする」ボタンが表示されます。 不足分のポイント(出目 − 目標値)を幸運から消費して、判定を成功に変えられます。 残り幸運はシートに反映され、消費済みの判定にはもう使えません。

🎲 プッシュロール

失敗した判定にもう一度だけ挑戦できます。プッシュ済みの判定は再プッシュできません。 失敗したときの「より重い代償」はキーパー(あなた)の裁量で。

ボーナス/ペナルティダイス

判定時に指定すると、10の位のダイスを複数振って有利/不利な方を採用します。

🌀 狂気表

6版は「一時的狂気」、7版は「狂気の発作(リアルタイム)」を1d10で引けます。結果は履歴にも残ります。

★ マイプリセット NEW

よく使うロールや判定を「★保存」しておくと、チップからワンタップで再実行できます (20件まで・同名は上書き)。保存先はブラウザなので、この端末専用のクイックパレットとして使えます。

ダイス演出 NEW

出目は一瞬シャッフルしてから確定します。クリティカル/イクストリーム成功はリングが輝き、 ファンブルは画面がシェイクします。 OSで「視差効果を減らす」を設定している場合は自動で無効になります。

基本機能

🕯️ 卓(セッション)管理

メニュー「卓管理」。人間同士で遊ぶセッションの管理ハブです。日程・参加者・シナリオを紐付け、当日はここが司令塔になります。

卓のライフサイクル

🪧 募集中
日程・シナリオ・参加探索者を設定
→
▶️ 進行中
戦闘・ログ・タイマーを活用
→
🏁 終了
あらすじ生成・記録

⏱️ セッションタイマー NEW

  • 卓の経過時間を表示。開始/一時停止/リセット
  • 休憩カウントダウン: 10分/30分/60分のプリセット。時間になると「休憩終了!」表示
  • 開始時刻はブラウザに保存されるため、リロードしても継続します

⚔️ 戦闘トラッカー

DEX順のイニシアチブ管理・HP増減・ラウンド送りに加え、武器攻撃に対応しています。

1参加者を追加
(PC=シートから / NPC=手動)
→
2DEX順で手番を進行
→
3⚔️ 攻撃 → 武器と対象を選ぶ
→
4命中判定→ダメージが
対象HPに自動反映

状態異常チップ NEW

「+状態」から 発狂・重傷・拘束・転倒・毒・隠密 などを付与(自由入力も可)。チップをクリックすると解除されます。

🩹 応急手当 NEW

ワンタップで1d3をロールしてHPを回復します。ロールは卓ログに記録されます。

装弾数管理 NEW

射撃武器は攻撃のたびに残弾が減り、弾切れになると「リロード」するまで撃てません。NPC武器の追加時に装弾数を指定できます。

👥 敵テンプレート NEW

チンピラ・カルト信者・警官・猛犬・異形のもの など8種をワンタップで戦闘に追加できます (武器・装弾数・運用メモ付き)。スタッツは本サイトオリジナルの汎用値で、同じテンプレを複数追加すると「チンピラ 2」のように自動で連番になります。

📜 卓ログ

ダイス履歴と、GMが手入力した出来事メモを時系列でまとめて表示します。戦闘の攻撃ロールもここに記録されます。 📝 あらすじ生成 要APIキー ボタンで、卓ログとダイス履歴からセッションのあらすじをAIに要約させて記録できます。

🐙 AI KP補佐 要APIキー

人間がキーパーを務める卓の相談相手です。NPCのセリフ案・情景描写・ルール裁定などをチャットで相談できます(進行そのものはしません)。

基本機能

📖 シナリオ管理

メニュー「シナリオ」。自作・既製シナリオの保存庫です。AI GMプレイのネタ元にもなります。

基本機能

  • シナリオ本文の保存・検索・タグ管理
  • 卓(セッション)やAI GMセッションに紐付けて利用

AIシナリオ自動生成 要APIキー

テーマ・舞台・ホラー度を指定すると、Claudeが導入・真相・NPC・手がかり・SANチェック・結末分岐を含むシナリオを生成します。生成後は自由に編集できます。

NPC・ハンドアウト資料

  • シナリオにNPC資料とハンドアウトを添付できます(画像付き可)
  • NPC資料はAI GMセッション作成時に自動でキーパーに連携され、AIがそのNPCを演じます

🤖 AI NPCジェネレータ 要APIキー NEW

1役どころを入力
「怪しい骨董屋の主人」など
→
2「生成」を押す
→
3NPC資料として自動保存

生成されるNPCには 名前・立場・外見・口調(セリフ例付き)・知っていること・秘密・簡易ステータス が含まれます。シナリオ本文の内容も加味されます。

AI機能

🐙 AI GMプレイ 要APIキー

メニュー「AI GM」。Claudeがキーパーとしてシナリオを進行します。ソロプレイでも、最大4人のパーティでも。

仕組み — ダイスはすべてサーバーが振る

判定・SANチェック・狂気表・幸運消費はすべてサーバー側で実際にダイスを振ります(tool use)。 AIが出目を勝手に決めることはありません。

1あなたが行動を宣言
→
2Claudeが判定を要求
→
3サーバーがダイスを振り記録
→
4結果を受けて物語が進む

セッションの作り方

  • 探索者を1〜4人選択(全員のHP/MP/SANを個別管理、7版は幸運も)
  • シナリオはライブラリから選ぶ・その場で書く・AIに生成させるの3通り
  • 6版/7版どちらのルールにも対応(版はメンバーの探索者に合わせます)

AI機能

🏕️ キャンペーン継続 NEW

終了したAI GMセッションから「▶ 続編を作る」。同じ探索者で第2話・第3話と物語をつなげられます。

続編を作る手順

1終了したセッションを開き
「▶ 続編を作る」
→
2📝 あらすじをAIで自動生成
(手書き・編集もOK)
→
3タイトル・シナリオを調整
→
4作成 → 第2話スタート!

引き継がれるもの

項目内容
探索者の状態HP/MP/SAN(7版は幸運も)を前回の最終状態から開始。削られたSANはそのまま
あらすじ新しいシナリオの末尾に「## 前回のあらすじ」として自動挿入。キーパーが前回の出来事を踏まえて進行します
メンバー前回と同じ探索者で自動作成
つながり一覧に「続編」バッジが付き、どのセッションの続きか分かります

あらすじの自動生成 要APIキー

前回セッションの会話ログ・判定・SANチェックから、キーパー用のあらすじ(300〜600字+探索者の状態)をAIが要約します。 生成結果は必ず編集できます。AIを使わず自分で書いても構いません(その場合APIキー不要)。

続きの続き(第3話、第4話…)も同じ手順で連鎖できます。人間卓でも卓ログの「📝 あらすじ生成」で同様の要約が作れます。

🧰 便利機能

プレイを支える周辺機能たちです。

🔍 横断検索(コマンドパレット) NEW

どのページからでも ⌘K / Ctrl+K(またはヘッダーの🔍)で検索パレットが開きます。 探索者・卓・シナリオ・AI GMセッションを名前で横断検索でき、空欄のままなら「探索者を新規作成」などのページジャンプとして使えます。 ↑↓で選択、Enterで移動。

📋 Markdown共有 NEW

  • キャラシート: 探索者詳細の「📋 Markdownコピー」で能力値・技能・武器をテキスト化。Discordにそのまま貼れます
  • 卓ログ: 卓ログパネルの「⬇ MD保存」で出来事メモ+ダイス履歴を時系列Markdownとしてダウンロード

📅 次回の卓予定 NEW

卓に開催日時を設定すると、ダッシュボードに「次回の卓予定」としてあと何日か付きで表示されます。ダッシュボード上部のクイックアクションからは、探索者作成・卓立て・AI GM・ダイスへワンタップで移動できます。

📈 全体統計 NEW

メニュー「統計」。全卓・AI GMセッションを横断した通算成績です。総判定数・成功率・クリファン数、d100出目分布、技能別成績、探索者別ランキング、月別アクティビティを表示します。

⭐ ピン留め NEW

探索者・シナリオの一覧にある ⭐ を押すと、その項目が一覧とダッシュボードの先頭に固定されます。もう一度押すと解除です。

🗑️ ゴミ箱 NEW

探索者・シナリオの削除はゴミ箱への移動になりました。ダッシュボードの「🗑️ ゴミ箱」から ♻️ 復元(プレイ履歴もそのまま戻ります)か完全削除を選べます。誤削除しても安心です。

📅 卓予定をカレンダーに登録 NEW

卓詳細の開催日時の横の「📅 カレンダーに登録」で .icsファイル をダウンロード。開くとGoogle/iOSカレンダーにそのまま予定として追加されます。

📊 プレイ統計

セッションごとに SAN推移グラフ・d100出目分布・成功率/クリファン率・技能別成績 を表示します。探索者シートの「プレイ記録」では通算成績も見られます。

📚 ルール早見表

メニュー「早見表」。6版/7版の判定・SAN・戦闘・成長ルールの要点をカード形式で参照できます。プレイ中のルール確認に。

💾 バックアップ

  • ダウンロード: 探索者・シナリオ・プレイログを含む全データをJSONで書き出し
  • 復元(インポート): バックアップJSONから全データを復元(現在のデータは置き換えられます)
立ち絵・資料画像もバックアップに同梱されます (v3形式)。旧形式 (v1/v2) のバックアップも画像なしで復元できます。※ローカル⇔Firebaseなど保存先の環境をまたいだ復元では画像リンクは引き継がれません。

📱 PWA(ホーム画面に追加)

ブラウザの「ホーム画面に追加/インストール」から、アプリのように起動できます。 一度開いたページはオフラインでも閲覧できます(新しいデータの読み込み・保存には接続が必要です)。

🎭 ココフォリア連携

探索者シートから、チャットパレット付きの駒データをクリップボードにコピーして、ココフォリアに貼り付けられます。

📄 リプレイ書き出し

AI GMセッションのログを、読み物風のMarkdownとしてダウンロードできます。

❓ 注意点とデータの仕組み

つまずきやすいポイントと、データがどう繋がっているかのまとめです。

注意点

項目内容
AI機能AI GM・KP補佐・シナリオ/NPC生成・あらすじ生成には ANTHROPIC_API_KEY の設定が必要です。未設定でもそれ以外の全機能は動作します
ログイン認証APP_PASSWORD を設定すると有効になります(単一ユーザー向け)。インターネットに公開する場合は必ず設定してください。ローカルでは未設定でOK
画像立ち絵などは public/uploads/ に保存され、バックアップJSONには含まれません
Charaeno7版のシートJSONが対象。武器・立ち絵は取り込まれません
オフラインPWAで閲覧できるのは初回に開いたことのあるページのみ。保存には接続が必要です

データの仕組み

  • 探索者(Character)は、人間卓にもAI GM卓にも参加できます
  • ダイスロール(DiceRoll)は卓またはAI GMセッションに紐づき、卓ログ・統計の元データになります
  • AIプレイ中のHP/MP/SANはセッション専用のスナップショット。マスターのシートには成長チェックで明示的に反映するまで影響しません
  • 続編セッションは 前のセッションへの参照 を持ち、1本の鎖としてつながります

セットアップ・公開について

インストール手順は同梱の README.md、クラウド公開(Firebase)の手順は DEPLOY.md を参照してください。
